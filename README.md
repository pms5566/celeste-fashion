# CÉLESTE — Luxury Fashion Atelier

> "Tailored for confidence since 2026."

CÉLESTE is a premium, single-page digital experience designed for a modern, minimalist luxury clothing brand. The site serves as a responsive visual editorial showcasing curated seasonal collections and lookbooks for modern, confident women.

---

## ✨ Features

- **Refined Aesthetics**: Deep Navy (`#0d1b3e`), Gold (`#c9a84c`), and Cream (`#f5ede0`) editorial palette.
- **Glassmorphic Navigation**: A fixed header that blurs and changes opacity smoothly on scroll, complete with an elegant scroll-progress indicator.
- **Dynamic Collection Grid**: Interactive product cards featuring smooth zoom transitions and slide-up "Explore" call-to-actions when hovered.
- **Visual Lookbook**: Sunset and dawn-lit editorial galleries styled with gold mesh radial guidelines.
- **Scroll Reveal**: Interactive smooth fade-ins and translates using native JavaScript `IntersectionObserver`.
- **Private Concierge Gateway**: Clean, minimal booking form with custom-styled luxury pathways for WhatsApp and Instagram.

---

## 🛠️ Built With

- **Structure & Logic**: HTML5, Vanilla JavaScript (no frameworks)
- **Styling**: Vanilla CSS (Responsive, Mobile-First)
- **Typography**: Google Fonts (*Cormorant Garamond* & *Montserrat*)
- **Assets**: Midjourney-grade custom AI fashion product photography
